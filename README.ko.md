# OBS 실시간 이중 언어 자막기 (Live Caption for OBS)

[繁體中文](README.md) | [English](README.en.md) | [日本語](README.ja.md) | [简体中文](README.zh-CN.md) | [한국어](README.ko.md)

스트리머, 방송 진행자 및 VTuber를 위해 특별히 설계된 OBS Studio용 실시간 음성 인식 및 이중 언어 번역 자막 도구입니다.

---

## ✨ 주요 기능

- 🎙️ **실시간 연속 음성 인식(STT)**: Web Speech API 기반 고정밀 음성 인식. 말하는 즉시 타이핑 미리보기를 제공하며, 문장이 끝나면 자동으로 확정됩니다.
- 🌐 **이중 언어 동시 표시 레이아웃**: 상단에 '원문', 하단에 '번역 자막'을 동시 표시하여 해외 시청자와의 원활한 소통을 지원합니다.
- 🟢 **크로마키(그린스크린) 지원 및 16:9 비율 고정**:
  - **엄격한 16:9 표준 비율 고정**: 미리보기 그린스크린 스테이지 및 전체 화면 그린 모드는 16:9(1920×1080)로 고정되어, 창 크기나 화면 비율(예: MacBook 16:10)에 관계없이 왜곡되지 않습니다.
  - **순수 그린스크린 모드**(단축키: `H` 또는 `Esc`): 상단 네비게이션 바, 사이드 설정 및 모든 버튼을 한 번의 클릭으로 숨기고 화면 전체를 깔끔한 자막 전용 그린스크린으로 전환합니다. (마우스 유휴 시 조작 버튼 자동 숨김)
  - 크로마 그린(`#00FF00`), 방송용 그린(`#00B140`), 블루스크린(`#0000FF`), 다크 배경(`#0F172A`) 및 투명 배경 지원.
  - 전용 OBS 브라우저 소스 오버레이(`overlay.html`)는 100% 알파 채널 투명 배경을 기본 지원합니다.
- ⚡ **WebSocket 및 BroadcastChannel 초저지연 스트리밍**: Google Chrome에서 마이크에 대고 말하면 OBS 화면에 지연 없이 즉시 동기화됩니다.
- 🎨 **디테일한 비주얼 커스터마이징**:
  - 외곽선(스트로크) 강도 조절 (밝은 게임 화면이나 복잡한 배경에서도 높은 가독성 유지)
  - 글꼴 크기 (작게, 보통, 크게, 매우 크게)
  - 수평 정렬 (가운데, 왼쪽, 오른쪽) 및 수직 위치 (하단, 중앙, 상단)
  - 원문 및 번역 자막 텍스트 색상 자유 변경 (기본값: 고대비 화이트 + 비비드 옐로우)
  - 음성이 없을 때 자동 페이드아웃 (3초, 5초, 8초 또는 숨기지 않음)
- 👤 **아바타 이미지 및 발화 펄스 애니메이션**: 스트리머 프로필 이미지나 커스텀 이미지를 자막 앞에 표시. 원형, 둥근 모서리, 사각형 프레임을 지원하며 말할 때 발화 호흡 펄스(Speaking Pulse)가 연동됩니다.
- 🎬 **해상도 연동 스테이지 특수효과**: 버튼 하나로 화려한 파티클 효과(불꽃놀이 🎆, 화면 깨짐 💥, 꽃다발 💐, 폭죽 🎉, 하트 💖, 번개 ⚡)를 연출. 1080p 및 4K 해상도에 맞게 대형 스케일로 연출됩니다.
- 🔄 **다중 번역 엔진 지원**: 서버 캐시, Chrome 온디바이스 AI Translation API(오프라인 고속 번역), Google GTX 및 MyMemory 자동 대체 지원.
- 🌍 **5개 국어 UI 완벽 지원 (i18n)**: 번체 중국어, 간체 중국어, 영어, 일본어, 한국어를 실시간으로 즉시 전환 가능.
- 📜 **음성 기록 및 내보내기**: 발화된 원문과 번역 기록을 실시간으로 저장하며, 클릭 한 번으로 TXT 파일로 내보낼 수 있습니다.

## 🚀 빠른 시작

터미널에서 프로젝트 디렉토리로 이동한 후 다음 명령을 실행합니다:

```bash
npm start
```

서버가 `http://localhost:3000`에서 실행됩니다.

## 📺 OBS 연결 방법 (2가지 중 선택)

### 방법 A: OBS '브라우저 소스' 사용 (적극 추천 ⭐⭐⭐⭐⭐)
> **장점**: 배경이 100% 완전 투명(알파 채널)으로 처리되어 글자 경계선이 가장 깨끗하며, 그린스크린 색 번짐(Color Bleed)이 없습니다.

1. 서버를 실행한 후 Google Chrome에서 제어판을 엽니다: `http://localhost:3000`.
2. 상단 툴바에서 **'📋 OBS 주소 복사'**를 클릭합니다 (주소: `http://localhost:3000/overlay.html`).
3. **OBS Studio**를 실행합니다:
   - '소스 목록' 패널에서 **+** 클릭 ➜ **브라우저 (Browser)** 선택.
   - 이름을 '이중 언어 실시간 자막' 등으로 설정.
   - 'URL'에 `http://localhost:3000/overlay.html` 입력.
   - '너비'를 **1920**, '높이'를 **1080**(또는 방송 캔버스 해상도)으로 설정.
   - 확인을 클릭합니다.
4. Chrome 제어판으로 돌아와 오른쪽 상단의 **'듣기 시작'**을 클릭하고 마이크에 대고 말하면 OBS 화면에 자막이 실시간으로 표시됩니다!

---

### 방법 B: OBS '윈도우 캡처' + 크로마키 필터
> **장점**: 서브 모니터에 Chrome 창을 직접 띄워두고 직관적으로 모니터링할 때 유용합니다.

1. Chrome 제어판에서 **'🟢 그린스크린 전체화면'**을 클릭합니다 (또는 `http://localhost:3000/overlay.html?bg=green` 열기).
2. **OBS Studio**를 실행합니다:
   - '소스 목록' 패널에서 **+** 클릭 ➜ **윈도우 캡처 (Window Capture)** 선택.
   - 그린스크린이 표시된 Chrome 창을 선택합니다.
3. 추가된 윈도우 캡처 소스를 **마우스 우클릭** ➜ **필터 (Filters)** 선택:
   - 필터 창 좌측 하단에서 **+** 클릭 ➜ **크로마 키 (Chroma Key)** 선택.
   - '키 색상 형식'을 **녹색 (Green)**으로 지정.
   - OBS가 자동으로 녹색 배경을 투명하게 제거하고 자막만 남깁니다!
4. 전체화면을 종료하려면 화면 오른쪽 상단의 버튼을 클릭하거나 `Esc` 키를 누릅니다.

## ⚙️ OBS 오버레이 URL 매개변수 설정

OBS 브라우저 소스 URL 뒤에 매개변수를 추가하여 표시 스타일을 직접 설정할 수 있습니다:

- `http://localhost:3000/overlay.html?mode=both` (기본값: 원문 + 번역 이중 언어 표시)
- `http://localhost:3000/overlay.html?mode=original` (원문 언어만 표시)
- `http://localhost:3000/overlay.html?mode=translation` (번역된 언어만 표시)
- `http://localhost:3000/overlay.html?bg=green` (그린스크린 배경 강제 적용)
- `http://localhost:3000/overlay.html?size=huge` (매우 큰 글꼴 크기)
- `http://localhost:3000/overlay.html?autohide=5` (5초 동안 무음일 때 자막 자동 숨김)
- `http://localhost:3000/overlay.html?stroke=thick` (굵은 검은색 외곽선)

## 💡 주의 사항

1. **브라우저 요구 사항**: 음성 인식은 Google Web Speech API를 사용하므로, **제어판(발화 입력창)은 반드시 Google Chrome 브라우저에서 실행해야 합니다**.
2. **마이크 권한**: 처음 실행할 때 브라우저에서 마이크 접근 권한을 요청하면 '허용'을 선택하세요.
3. 방송 중에는 터미널에서 `npm start` 프로세스를 계속 실행해 두어야 합니다.
