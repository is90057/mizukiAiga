# Mizuki Aiga - OBS 실시간 이중 언어 자막기 (Live Caption for OBS)

[繁體中文](README.md) | [English](README.en.md) | [日本語](README.ja.md) | [简体中文](README.zh-CN.md) | [한국어](README.ko.md)

스트리머, 방송 진행자 및 VTuber를 위해 특별히 설계된 OBS Studio용 실시간 음성 인식 및 이중 언어 번역 자막 도구입니다.

---

## 📖 프로젝트 배경 및 이름의 유래

본 프로젝트는 원래 **아이가 미즈키(藍芽水月, Aiga Mizuki)**와의 합동 방송을 위해 OBS Studio에 초고속 음성 인식과 이중 언어 실시간 번역 자막을 제공하고자 전용 개발되었던 시스템에서 출발하여, 단독 방송 워크플로우로 분류 및 최적화된 시스템입니다. 이 소중한 합동 방송 탄생의 계기를 기념하기 위해 프로젝트명을 **Mizuki Aiga**로 공식 명명하였습니다.

---

## 🧩 하위 시스템 모듈 아키텍처 소개

본 시스템은 고도로 모듈화된 여러 독립 하위 시스템이 유기적으로 연동되어 동작합니다:

1. **🎙️ 메인 제어 콘솔 시스템 (Web Control Panel - `/`)**
   - 방송 진행자의 마이크 오디오를 수음하여 Google Web Speech API 기반으로 실시간 연속 음성 인식을 수행합니다.
   - 스마트 문장 종결 처리, 실시간 음량 VU 미터 모니터링, 마이크 입력 장치 스캔 및 전환, 디지털 게인(증폭) 조절 지원.
   - 5개 언어 UI 실시간 즉시 전환(번체, 일본어, 영어, 간체, 한국어) 및 Chrome 브라우저 자동 감지 기능(비 Chrome 브라우저 경고 팝업).
   - 빠른 템플릿 문구 전송 보드 및 발화/번역 텍스트 기록 내보내기(TXT) 지원.

2. **📺 OBS 전용 투명 오버레이 시스템 (OBS Overlay Browser Source - `/overlay.html`)**
   - OBS Studio의 '브라우저 소스(Browser Source)' 전용으로 특화된 렌더링 캔버스입니다.
   - **100% 완전 투명 알파 채널**을 기본 탑재하여 크로마키 세팅이나 녹색 번짐(Color Bleed) 없이 글씨 외곽선이 선명하게 표현됩니다.
   - WebSocket 및 BroadcastChannel을 통해 메인 콘솔과 지연 시간 0초로 즉시 동기화됩니다.
   - URL 매개변수를 통한 폰트 크기, 정렬, 표시 모드, 자동 페이드아웃 시간 등 상세 커스텀 지원.

3. **🟢 크로마키 전체화면 방송 스테이지 (Chroma Key Green Stage - `?bg=green`)**
   - 보조 모니터에서 '윈도우 캡처(Window Capture)'를 선호하는 스트리머를 위한 전용 화면.
   - **엄격한 16:9 표준 비율 고정**: 기기 화면 비율(예: MacBook 16:10)에 관계없이 16:9 비율을 유지하여 OBS 캔버스에 왜곡 없이 완벽히 들어맞습니다.
   - **순수 그린스크린 모드**(단축키: `H` 또는 `Esc`) 지원으로 마우스 유휴 시 조작 버튼이 자동 숨김 처리되어 가장 깔끔한 윈도우 캡처 환경을 제공합니다.

4. **🌐 다중 엔진 스마트 장애 대비 번역 서비스 (Multi-Engine Translation Service - `/api/translate`)**
   - **Chrome 온디바이스 AI 오프라인 번역**: Chrome 브라우저 내장 Translation API를 활용하여 네트워크 트래픽 없이 수 밀리초 만에 초고속 번역 수행.
   - **클라우드 다중 폴백 백업**: 서버 메모리 캐시 + Google GTX 및 MyMemory 엔진을 통합하여 네트워크 불안정 시에도 끊김 없이 번역을 유지합니다.

5. **🎬 방송 파티클 및 시각 특수효과 시스템 (Visual & Particle FX System - `effects.js`)**
   - 물리 엔진이 적용된 고화질 파티클 효과 6종(불꽃놀이 🎆, 화면 깨짐 💥, 꽃다발 💐, 폭죽 🎉, 하트 💖, 번개 ⚡)을 버튼 하나로 연출.
   - 1080p 및 4K 해상도에 맞춰 크기, 속도, 중력이 등비로 확대 연출되어 대형 캔버스에서도 웅장한 효과를 발휘합니다.
   - 스트리머 커스텀 아바타 이미지 업로드 및 말할 때 발화 호흡 펄스(Speaking Pulse) 연동.

## ✨ 주요 기능

- 🎙️ **실시간 연속 음성 인식(STT)**: 말하는 즉시 타이핑 미리보기를 제공하며, 문장이 끝나면 자동으로 확정됩니다.
- 🌐 **이중 언어 동시 표시 레이아웃**: 상단에 '원문', 하단에 '번역 자막'을 동시 표시.
- 🟢 **크로마키(그린스크린) 지원 및 16:9 비율 고정**:
  - 엄격한 16:9 표준 비율 고정 (1920×1080).
  - 순수 그린스크린 모드 (`H` 또는 `Esc`).
  - 크로마 그린, 방송용 그린, 블루스크린, 다크 배경 및 투명 배경 지원.
- ⚡ **WebSocket 및 BroadcastChannel 초저지연 스트리밍**: Chrome에서 OBS로 지연 없이 동기화.
- 🎨 **디테일한 비주얼 커스터마이징**: 외곽선 강도, 글꼴 크기, 텍스트 색상, 자동 페이드아웃 설정.
- 👤 **아바타 이미지 및 발화 펄스 애니메이션**: 말할 때 반응하는 아바타 연동.
- 🎬 **해상도 연동 스테이지 특수효과**: 6종의 파티클 이펙트.
- 🌍 **5개 국어 UI 완벽 지원 (i18n)**: 번체, 간체, 영어, 일본어, 한국어 즉시 전환.
- 📜 **음성 기록 및 내보내기**: 원클릭 TXT 파일 내보내기.

## 🚀 빠른 시작

터미널에서 프로젝트 디렉토리로 이동한 후 다음 명령을 실행합니다:

```bash
npm start
```

서버가 `http://localhost:3000`에서 실행됩니다.

## 📺 OBS 연결 방법 (2가지 중 선택)

### 방법 A: OBS '브라우저 소스' 사용 (적극 추천 ⭐⭐⭐⭐⭐)
> **장점**: 배경이 100% 완전 투명(알파 채널)으로 처리되어 글자 경계선이 가장 깨끗하며, 그린스크린 색 번짐(Color Bleed)이 없습니다.

1. 서버를 실행한 후 Google Chrome에서 제어판을 엽니다: `http://localhost:3000`.
2. 상단 툴바에서 **'📋 OBS 주소 복사'**를 클릭합니다 (주소: `http://localhost:3000/overlay.html`).
3. **OBS Studio**를 실행합니다:
   - '소스 목록' 패널에서 **+** 클릭 ➜ **브라우저 (Browser)** 선택.
   - 이름을 '이중 언어 실시간 자막' 등으로 설정.
   - 'URL'에 `http://localhost:3000/overlay.html` 입력.
   - '너비'를 **1920**, '높이'를 **1080**(또는 방송 캔버스 해상도)으로 설정.
   - 확인을 클릭합니다.
4. Chrome 제어판으로 돌아와 오른쪽 상단의 **'듣기 시작'**을 클릭하고 마이크에 대고 말하면 OBS 화면에 자막이 실시간으로 표시됩니다!

---

### 방법 B: OBS '윈도우 캡처' + 크로마키 필터
> **장점**: 서브 모니터에 Chrome 창을 직접 띄워두고 직관적으로 모니터링할 때 유용합니다.

1. Chrome 제어판에서 **'🟢 그린스크린 전체화면'**을 클릭합니다 (또는 `http://localhost:3000/overlay.html?bg=green` 열기).
2. **OBS Studio**를 실행합니다:
   - '소스 목록' 패널에서 **+** 클릭 ➜ **윈도우 캡처 (Window Capture)** 선택.
   - 그린스크린이 표시된 Chrome 창을 선택합니다.
3. 추가된 윈도우 캡처 소스를 **마우스 우클릭** ➜ **필터 (Filters)** 선택:
   - 필터 창 좌측 하단에서 **+** 클릭 ➜ **크로마 키 (Chroma Key)** 선택.
   - '키 색상 형식'을 **녹색 (Green)**으로 지정.
   - OBS가 자동으로 녹색 배경을 투명하게 제거하고 자막만 남깁니다!
4. 전체화면을 종료하려면 화면 오른쪽 상단의 버튼을 클릭하거나 `Esc` 키를 누릅니다.

## ⚙️ OBS 오버레이 URL 매개변수 설정

OBS 브라우저 소스 URL 뒤에 매개변수를 추가하여 표시 스타일을 직접 설정할 수 있습니다:

- `http://localhost:3000/overlay.html?mode=both` (기본값: 원문 + 번역 이중 언어 표시)
- `http://localhost:3000/overlay.html?mode=original` (원문 언어만 표시)
- `http://localhost:3000/overlay.html?mode=translation` (번역된 언어만 표시)
- `http://localhost:3000/overlay.html?bg=green` (그린스크린 배경 강제 적용)
- `http://localhost:3000/overlay.html?size=huge` (매우 큰 글꼴 크기)
- `http://localhost:3000/overlay.html?autohide=5` (5초 동안 무음일 때 자막 자동 숨김)
- `http://localhost:3000/overlay.html?stroke=thick` (굵은 검은색 외곽선)

## 💡 주의 사항

1. **브라우저 요구 사항**: 음성 인식은 Google Web Speech API를 사용하므로, **제어판(발화 입력창)은 반드시 Google Chrome 브라우저에서 실행해야 합니다**(시스템 내 자동 감지 기능 탑재로 비 Chrome 브라우저 실행 시 안내 팝업이 표시됩니다).
2. **마이크 권한**: 처음 실행할 때 브라우저에서 마이크 접근 권한을 요청하면 '허용'을 선택하세요.
3. 방송 중에는 터미널에서 `npm start` 프로세스를 계속 실행해 두어야 합니다.
