# OBS リアルタイムバイリンガル字幕 (Live Caption for OBS)

[繁體中文](README.md) | [English](README.en.md) | [日本語](README.ja.md) | [简体中文](README.zh-CN.md) | [한국어](README.ko.md)

配信者（ストリーマー）、ゲーム実況者、VTuber向けに特別設計された、OBS Studio用リアルタイム音声認識＆多言語バイリンガル翻訳字幕ツールです。

---

## ✨ 主な機能

- 🎙️ **リアルタイム連続音声認識**：Web Speech APIによる高精度な音声入力。話している最中にリアルタイムタイピング表示、文末自動確定。
- 🌐 **バイリンガル同時表示レイアウト**：上部に「原文」、下部に「翻訳字幕」を表示。国内外のリスナーとのコミュニケーションを円滑にします。
- 🟢 **クロマキー（グリーンバック）対応＆16:9比率固定**：
  - **厳密な16:9標準比率ロック**：プレビュー画面および全画面グリーンバックモードは16:9（1920×1080）に固定。ウィンドウサイズや画面比率（MacBookの16:10など）に関わらず歪みません。
  - **純粋グリーンバックモード**（ショートカットキー：`H` または `Esc`）：ナビゲーションバーや設定パネルをワンクリックで非表示にし、画面全体をグリーンバック字幕のみに切り替えます（マウス静止時は操作ボタン自動非表示）。
  - 純緑（`#00FF00`）、放送用グリーン（`#00B140`）、ブルーバック（`#0000FF`）、ダーク背景（`#0F172A`）、透過背景に対応。
  - OBS専用のブラウザソース用オーバーレイ（`overlay.html`）は、完全透過（Alphaチャンネル）にネイティブ対応。
- ⚡ **WebSocket＆BroadcastChannel リアルタイム同期**：Google Chromeのマイクに向かって話すだけで、OBS画面上に遅延ゼロで字幕が同期されます。
- 🎨 **高度なビジュアルカスタマイズ**：
  - 黒縁のアウトライン強度（明るいゲーム画面でも視認性を維持）
  - フォントサイズ（小・中・大・特大）
  - 水平配置（中央・左揃え・右揃え）と垂直位置（下部・中央・上部）
  - 原文と翻訳の文字色（デフォルト：高コントラスト白＋鮮やかイエロー）
  - 無音時の自動フェードアウト（3秒・5秒・8秒・非表示なし）
- 👤 **アイコン画像表示＆発話呼吸エフェクト**：配信者アイコンを字幕の先頭に表示。丸型・角丸・正方形枠に対応し、話している最中にアニメーション（Speaking Pulse）が連動。
- 🎬 **解像度連動ステージエフェクト**：ボタン一つで迫力ある画面エフェクト（花火 🎆、画面割れ 💥、花束 💐、クラッカー 🎉、ハート 💖、落雷 ⚡）を発動。1080p/4K解像度に合わせて迫力あるスケールで表示されます。
- 🔄 **マルチ翻訳エンジン対応**：サーバーキャッシュ、Chrome内蔵AI Translation API（完全オフライン＆超高速）、Google GTX、MyMemoryによる冗長性確保。
- 🌍 **5言語対応UI（多言語化）**：繁体字中国語、簡体字中国語、英語、日本語、韓国語をリアルタイムで瞬時に切り替え可能。
- 📜 **文字起こし履歴とエクスポート**：話した原文と翻訳をリアルタイムで記録し、ワンクリックでTXT形式で出力可能。

## 🚀 クイックスタート

ターミナルでプロジェクトディレクトリに移動し、以下のコマンドを実行します：

```bash
npm start
```

サーバーが `http://localhost:3000` で起動します。

---

## 📺 OBS 連携手順（2つの方法から選択）

### 方法 A：OBS「ブラウザソース」（推奨 ⭐⭐⭐⭐⭐）
> **メリット**：背景が100%完全透過（Alphaチャンネル）になり、文字の縁が非常に鮮明で、グリーンバックの色被り（カラーブリード）が一切ありません。

1. サーバーを起動後、Google Chromeでコントロールパネルを開きます：`http://localhost:3000`。
2. 上部ツールバーの「**📋 OBS URLをコピー**」をクリック（URL: `http://localhost:3000/overlay.html`）。
3. **OBS Studio** を起動：
   - 「ソース」パネルの「**+**」をクリック ➜ 「**ブラウザ**」を選択。
   - 名前を「バイリンガル字幕」などに設定。
   - 「URL」に `http://localhost:3000/overlay.html` を貼り付け。
   - 「幅」を **1920**、「高さ」を **1080**（または配信キャンバスと同じサイズ）に設定。
   - 「OK」をクリック。
4. Chromeのコントロールパネルに戻り、右上の「**聞き取り開始**」をクリックしてマイクに向かって話すと、OBS画面に字幕がリアルタイムで同期されます！

---

### 方法 B：OBS「ウィンドウキャプチャ」＋「クロマキー合成」
> **メリット**：サブモニターにChromeウィンドウを直接置いて視覚的に監視したい場合に便利です。

1. Chromeのコントロールパネルで「**🟢 全画面グリーン**」をクリック（または `http://localhost:3000/overlay.html?bg=green` を開く）。
2. **OBS Studio** を起動：
   - 「ソース」パネルの「**+**」をクリック ➜ 「**ウィンドウキャプチャ**」を選択。
   - グリーンバックを表示しているChromeウィンドウを選択。
3. 追加したウィンドウキャプチャソースを**右クリック** ➜ 「**フィルタ**」を選択：
   - 左下の「**+**」をクリック ➜ 「**クロマキー**」を選択。
   - 「色キーの種類」を「**緑**」に設定。
   - OBSが自動的に緑色の背景を透過し、字幕のみが残ります！
4. 全画面グリーンバックを終了するには、画面右上のボタンをクリックするか `Esc` キーを押します。

## ⚙️ OBS オーバーレイ URL パラメータ一覧

OBSブラウザソースのURL末尾にパラメータを追加することで、表示スタイルを直接指定できます：

- `http://localhost:3000/overlay.html?mode=both`（デフォルト：原文＋翻訳のバイリンガル表示）
- `http://localhost:3000/overlay.html?mode=original`（原文言語のみ表示）
- `http://localhost:3000/overlay.html?mode=translation`（翻訳言語のみ表示）
- `http://localhost:3000/overlay.html?bg=green`（強制グリーンバック背景）
- `http://localhost:3000/overlay.html?size=huge`（特大フォントサイズ）
- `http://localhost:3000/overlay.html?autohide=5`（無音5秒後に自動非表示）
- `http://localhost:3000/overlay.html?stroke=thick`（太い黒縁）

## 💡 ご注意

1. **対応ブラウザ**：音声認識にはGoogle Web Speech APIを使用するため、**コントロールパネル（音声入力側）は必ず Google Chrome ブラウザで開いてください**。
2. **マイク権限**：初回起動時にブラウザからマイク使用の許可を求められますので、「許可」を選択してください。
3. 配信中はターミナルで `npm start` を実行したままにしてください。
