# Mizuki Aiga - OBS リアルタイムバイリンガル字幕 (Live Caption for OBS)

[繁體中文](README.md) | [English](README.en.md) | [日本語](README.ja.md) | [简体中文](README.zh-CN.md) | [한국어](README.ko.md)

配信者（ストリーマー）、実況者、VTuber向けに特別設計された、OBS Studio用リアルタイム音声認識＆多言語バイリンガル翻訳字幕ツールです。

---

## 📖 プロジェクトの背景と命名の由来

本プロジェクトは、元々 **藍芽水月（Aiga Mizuki）** とのコラボ配信において、OBS Studio向けに超高速な音声認識とバイリンガル翻訳字幕を届けるために専用開発されたシステムから、実況ワークフローとして独立・最適化されたものです。このコラボ配信の誕生を記念し、正式名称として **Mizuki Aiga** と命名されました。

---

## 🧩 各サブシステムのアーキテクチャ紹介

本システムは、高度にモジュール化された複数の独立したサブシステムが連携して動作します：

1. **🎙️ メインコントロールパネル (`/`)**
   - 配信者のマイク音声を拾い、Google Web Speech API を用いて連続リアルタイム音声認識を実行。
   - スマートな文末確定処理、リアルタイム音量メーター（VU Meter）、マイク入力デバイスの切り替え、デジタルゲイン調整を搭載。
   - 5言語UIの即時切り替え（繁體中文、日本語、English、简体中文、한국어）に対応し、Chrome ブラウザ自動検知（非Chromeブラウザへの警告ポップアップ）を内蔵。
   - クイック定型文送信ボード（テンプレート）および文字起こし履歴エクスポート（TXT）機能を備えています。

2. **📺 OBS専用透過オーバーレイ (`/overlay.html`)**
   - OBS Studio の「ブラウザソース（Browser Source）」専用に設計されたレンダリング画面。
   - **100% ネイティブの Alpha 透過チャンネル**を備え、クロマキー合成のような輪郭の調整やグリーンの色被り（カラーブリード）が一切ありません。
   - WebSocket および BroadcastChannel により、コントロールパネルと完全遅延ゼロでリアルタイム同期。
   - URLパラメータによる柔軟なスタイル指定（文字サイズ、配置、表示モード、自動フェードアウト時間など）に対応。

3. **🟢 クロマキー全画面配信ステージ (`?bg=green`)**
   - サブモニターで「ウィンドウキャプチャ」を行いたい配信者向け。
   - **厳密な16:9黄金比ロック**：PC環境の画面比率（MacBookの16:10等）に関わらず、OBSの16:9配信画面に合わせて等比率を完全維持。
   - 「**🔲 機能バー非表示（純粋グリーンバックモード）**」（ショートカット：`H` または `Esc`）に対応し、マウス停止時はボタンを自動非表示にしてクリーンなウィンドウキャプチャを提供。

4. **🌐 マルチエンジン自動冗長翻訳サービス (`/api/translate`)**
   - **ChromeオンデバイスAIオフライン翻訳**：Chrome内蔵の AI Translation API を活用し、ネットワーク不要の数ミリ秒応答を実現。
   - **クラウド多重冗長バックアップ**：サーバーインメモリキャッシュ ＋ Google GTX および MyMemory 翻訳エンジンを統合し、通信不安定時も自動でフォールバックして配信中の翻訳を維持。

5. **🎬 配信パーティクル＆ビジュアル演出システム (`effects.js`)**
   - 物理演算を組み込んだ高画質パーティクルエンジンを内蔵し、6種類の大規模演出（花火 🎆、画面割れ 💥、花束 💐、クラッカー 🎉、ハート 💖、落雷 ⚡）をワンクリックで発動。
   - 1080pおよび4K解像度に合わせてパーティクルサイズや速度が等比拡大され、大迫力で表示。
   - 配信者のカスタムアイコンアップロードと発話呼吸アニメーション（Speaking Pulse）に対応。

## ✨ 主な機能

- 🎙️ **リアルタイム連続音声認識**：話している最中にリアルタイムタイピング表示、文末自動確定。
- 🌐 **バイリンガル同時表示レイアウト**：上部に「原文」、下部に「翻訳字幕」を表示。
- 🟢 **クロマキー（グリーンバック）対応＆16:9比率固定**：
  - 厳密な16:9標準比率ロック（1920×1080）。
  - 純粋グリーンバックモード（`H` または `Esc`）。
  - 純緑（`#00FF00`）、放送用グリーン（`#00B140`）、ブルーバック（`#0000FF`）、ダーク背景（`#0F172A`）、透過背景に対応。
- ⚡ **WebSocket＆BroadcastChannel リアルタイム同期**：遅延ゼロでOBSへ即座に反映。
- 🎨 **高度なビジュアルカスタマイズ**：黒縁アウトライン、フォントサイズ、配置、色、自動フェードアウト。
- 👤 **アイコン画像表示＆発話呼吸エフェクト**：配信者アイコンと連動アニメーション。
- 🎬 **解像度連動ステージエフェクト**：画面演出パーティクルシステム。
- 🌍 **5言語対応UI（多言語化）**：繁中、簡中、英語、日本語、韓国語の即時切り替え。
- 📜 **文字起こし履歴とエクスポート**：ワンクリックでTXT形式で出力可能。

## 🚀 クイックスタート

ターミナルでプロジェクトディレクトリに移動し、以下のコマンドを実行します：

```bash
npm start
```

サーバーが `http://localhost:3000` で起動します。

## 📺 OBS 連携手順（2つの方法から選択）

### 方法 A：OBS「ブラウザソース」（推奨 ⭐⭐⭐⭐⭐）
> **メリット**：背景が100%完全透過（Alphaチャンネル）になり、文字の縁が非常に鮮明で、グリーンバックの色被り（カラーブリード）が一切ありません。

1. サーバーを起動後、Google Chromeでコントロールパネルを開きます：`http://localhost:3000`。
2. 上部ツールバーの「**📋 OBS URLをコピー**」をクリック（URL: `http://localhost:3000/overlay.html`）。
3. **OBS Studio** を起動：
   - 「ソース」パネルの「**+**」をクリック ➜ 「**ブラウザ**」を選択。
   - 名前を「バイリンガル字幕」などに設定。
   - 「URL」に `http://localhost:3000/overlay.html` を貼り付け。
   - 「幅」を **1920**、「高さ」を **1080**（または配信キャンバスと同じサイズ）に設定。
   - 「OK」をクリック。
4. Chromeのコントロールパネルに戻り、右上の「**聞き取り開始**」をクリックしてマイクに向かって話すと、OBS画面に字幕がリアルタイムで同期されます！

---

### 方法 B：OBS「ウィンドウキャプチャ」＋「クロマキー合成」
> **メリット**：サブモニターにChromeウィンドウを直接置いて視覚的に監視したい場合に便利です。

1. Chromeのコントロールパネルで「**🟢 全画面グリーン**」をクリック（または `http://localhost:3000/overlay.html?bg=green` を開く）。
2. **OBS Studio** を起動：
   - 「ソース」パネルの「**+**」をクリック ➜ 「**ウィンドウキャプチャ**」を選択。
   - グリーンバックを表示しているChromeウィンドウを選択。
3. 追加したウィンドウキャプチャソースを**右クリック** ➜ 「**フィルタ**」を選択：
   - 左下の「**+**」をクリック ➜ 「**クロマキー**」を選択。
   - 「色キーの種類」を「**緑**」に設定。
   - OBSが自動的に緑色の背景を透過し、字幕のみが残ります！
4. 全画面グリーンバックを終了するには、画面右上のボタンをクリックするか `Esc` キーを押します。

## ⚙️ OBS オーバーレイ URL パラメータ一覧

OBSブラウザソースのURL末尾にパラメータを追加することで、表示スタイルを直接指定できます：

- `http://localhost:3000/overlay.html?mode=both`（デフォルト：原文＋翻訳のバイリンガル表示）
- `http://localhost:3000/overlay.html?mode=original`（原文言語のみ表示）
- `http://localhost:3000/overlay.html?mode=translation`（翻訳言語のみ表示）
- `http://localhost:3000/overlay.html?bg=green`（強制グリーンバック背景）
- `http://localhost:3000/overlay.html?size=huge`（特大フォントサイズ）
- `http://localhost:3000/overlay.html?autohide=5`（無音5秒後に自動非表示）
- `http://localhost:3000/overlay.html?stroke=thick`（太い黒縁）

## 💡 ご注意

1. **対応ブラウザ**：音声認識にはGoogle Web Speech APIを使用するため、**コントロールパネル（音声入力側）は必ず Google Chrome ブラウザで開いてください**（自動検知機能が搭載されており、Chrome 以外のブラウザで開いた場合はポップアップで警告されます）。
2. **マイク権限**：初回起動時にブラウザからマイク使用の許可を求められますので、「許可」を選択してください。
3. 配信中はターミナルで `npm start` を実行したままにしてください。
