# Mizuki Aiga - OBS 即時雙語字幕機 (Live Caption for OBS)

[繁體中文](README.md) | [English](README.en.md) | [日本語](README.ja.md) | [简体中文](README.zh-CN.md) | [한국어](README.ko.md)

專為直播主、實況主與 VTuber 設計的 OBS Studio 即時語音辨識與雙語翻譯字幕工具。

---

## 📖 專案背景與命名由來

本專案最初是為了與 **藍芽水月（Aiga Mizuki）** 聯動直播時，為 OBS Studio 提供即時語音辨識與雙語翻譯字幕而量身打造的專用系統，隨後自該實況需求獨立分流優化而成。為紀念這次合作直播的誕生契機，專案正式命名為 **Mizuki Aiga**。

---

## 🧩 各子系統架構介紹

本系統由多個高度模組化的獨立子系統協同運作：

1. **🎙️ 主控工作台系統 (Web Control Panel - `/`)**
   - 負責主播麥克風音訊採集與 Google Web Speech API 語音連續聽寫。
   - 支援智慧斷句結算、即時音量跳動監控（VU Meter）、麥克風裝置掃描切換與數位增益控制。
   - 提供 5 國 UI 語系無縫切換（繁中、日文、英文、簡中、韓文），並內建 Chrome 瀏覽器環境自動偵測（非 Chrome 瀏覽器自動彈窗警示）。
   - 具備快速常用語廣播板（快捷模板）與辨識歷史紀錄導出（TXT 筆記）。

2. **📺 OBS 專屬透明圖層系統 (OBS Overlay Browser Source - `/overlay.html`)**
   - 專為 OBS Studio「瀏覽器來源 (Browser Source)」打造的純粹渲染畫布。
   - 具備 **100% 原生 Alpha 透明通道**，文字描邊乾淨俐落，完全免除傳統色度鍵的去背調校與綠光色溢問題。
   - 透過 WebSocket 與 BroadcastChannel 與控制台達成 0 延遲即時同步。
   - 支援完整的 URL Query 參數自訂（字級、對齊、排版模式、自動隱藏秒數等）。

3. **🟢 色度鍵全螢幕實況舞台 (Chroma Key Green Stage - `?bg=green`)**
   - 專門為喜愛使用副螢幕「視窗擷取 (Window Capture)」的主播打造。
   - **嚴格 16:9 黃金比例鎖定**：無論主機螢幕規格（如 MacBook 16:10），綠幕舞台皆強制等比縮放，對齊 OBS 16:9 實況畫布不變形。
   - 支援「**🔲 隱藏功能欄（純綠幕模式）**」（快捷鍵：`H` 或 `Esc`），滑鼠閒置時自動隱藏操作鈕，打造最純淨的綠幕視窗。

4. **🌐 多引擎智慧容錯翻譯系統 (Multi-Engine Translation Service - `/api/translate`)**
   - **本機 Chrome 離線翻譯**：支援 Chrome 內建 AI Translation API，免走網路、毫秒級極速回應。
   - **雲端多重容錯備援**：整合伺服器記憶體快取 + Google GTX 與 MyMemory 翻譯引擎，遇網路波動自動平滑切換，確保實況翻譯永不中斷。

5. **🎬 實況粒子與動態視覺系統 (Visual & Particle FX System - `effects.js`)**
   - 內建高畫質粒子實體運算引擎，支援一鍵施放 6 種大型實況特效（煙火 🎆、碎屏 💥、送花 💐、彩帶 🎉、愛心 💖、雷電 ⚡）。
   - 特效速度、數量與重力全面支援 16:9 高解析度自適應等比放大，在 1080p/4K 畫布上呈現飽滿震撼張力。
   - 支援主播自訂頭像上傳，並連動動態發話呼吸律動（Speaking Pulse）。

## ✨ 特色亮點

- 🎙️ **即時語音連續聽寫**：基於 Web Speech API 高辨識率語音辨識，說話時即時打字預覽，斷句時自動結算。
- 🌐 **雙語同步排版**：上方顯示「原文」、下方顯示「翻譯字幕」，完美符合實況觀眾與外語觀眾交流需求。
- 🟢 **綠幕（Chroma Key）支援與 16:9 黃金比例**：
  - **嚴格 16:9 標準比例鎖定**：預覽綠幕舞台與純綠幕模式皆強制鎖定為 16:9（1920×1080 規格），串接至 OBS 時完美吻合 16:9 實況畫布！
  - 支援一鍵「**🔲 隱藏功能欄（純綠幕模式）**」（快捷鍵：`H` 或 `Esc`）：瞬間隱藏導覽列與側邊設定，滑鼠閒置時自動隱藏控制按鈕。
  - 支援純綠幕（`#00FF00`）、專業實況綠（`#00B140`）、藍幕（`#0000FF`）與全螢幕模式。
- ⚡ **WebSocket + BroadcastChannel 即時串流**：在 Chrome 網頁中對麥克風說話，OBS 畫面即刻 0 延遲同步顯示字幕。
- 🎨 **高度客製化外觀**：
  - 黑邊描邊強度（防止在亮色遊戲畫面或複雜背景上看不清）
  - 字體大小（小、中、大、特大）
  - 水平對齊（置中、靠左、靠右）與垂直位置（底部、置中、頂部）
  - 原文與翻譯顏色自由選擇（預設高對比白 + 亮黃）
  - 無語音時自動淡出隱藏（可設定 3 秒、5 秒、8 秒或永不隱藏）
- 👤 **字幕前置頭像 / 圖片**：支援自行上傳主播頭像或自訂圖片，自動顯示在字幕最前端，說話時自帶動態呼吸律動（Speaking Pulse）！
- 🎬 **實況即時綠幕特效欄**：放煙火 🎆、砸破螢幕玻璃 💥、浪漫送花 💐、派對彩帶拉炮 🎉、滿滿愛心 💖、雷電轟頂 ⚡。
- 🌍 **完整多語系支援 (i18n)**：繁中、簡中、英文、日文、韓文即時切換。
- 📜 **歷史紀錄與匯出**：即時記錄說過的每一句原文與翻譯，支援一鍵匯出為 TXT 筆記。

## 🚀 快速啟動

在終端機進入專案目錄並執行：

```bash
npm start
```

伺服器將在 `http://localhost:3000` 啟動。

## 📺 OBS 串接方式（兩種任選）

### 方案 A：OBS「瀏覽器來源」（最推薦 ⭐⭐⭐⭐⭐）
> **優勢**：背景自動為 100% 純透明（Alpha 通道），文字邊緣最乾淨、無綠幕反光色溢（Color Bleed）。

1. 啟動伺服器後，在瀏覽器打開控制面板：`http://localhost:3000`。
2. 點擊頂部工具列的「**📋 複製 OBS 網址**」（網址為：`http://localhost:3000/overlay.html`）。
3. 打開 **OBS Studio**：
   - 在「來源」面板中點選「**+**」➜ 選擇「**瀏覽器 (Browser)**」。
   - 名稱可取名為「雙語即時字幕」。
   - 將「URL」設為：`http://localhost:3000/overlay.html`。
   - 將「寬度」設為 **1920**，「高度」設為 **1080**（或與您的實況畫布相同）。
   - 點擊確定。
4. 回到 Chrome 控制網頁，點擊右上角「**開始聆聽**」並對著麥克風說話，OBS 畫面就會自動同步出現雙語字幕！

---

### 方案 B：OBS「視窗擷取」+「色度鍵綠幕過濾」
> **優勢**：可直接將 Chrome 視窗獨立放置在副螢幕上，直覺監看。

1. 在 Chrome 控制網頁中點擊「**🟢 綠幕全螢幕**」（或直接開啟 `http://localhost:3000/overlay.html?bg=green`）。
2. 打開 **OBS Studio**：
   - 在「來源」面板點選「**+**」➜ 選擇「**視窗擷取 (Window Capture)**」。
   - 選擇剛剛開啟綠幕的 Chrome 視窗。
3. 在該視窗來源上點擊**右鍵** ➜ 選擇「**濾鏡 (Filters)**」：
   - 在左下角點選「**+**」➜ 選擇「**色度鍵 (Chroma Key)**」。
   - 「鍵值顏色類型」選擇「**綠色 (Green)**」。
   - OBS 會自動將純綠色背景掏空透明，只保留雙語字幕！
4. 點擊 Chrome 畫面右上角的「退出綠幕全螢幕」或按鍵盤 `Esc` 即可恢復控制介面。

## ⚙️ 參數進階調整（OBS Overlay URL 參數）

若使用 OBS 瀏覽器來源，亦可直接在網址後方帶入參數，例如：

- `http://localhost:3000/overlay.html?mode=both`（預設，雙語顯示：上方原文、下方翻譯）
- `http://localhost:3000/overlay.html?mode=original`（僅顯示原文語言）
- `http://localhost:3000/overlay.html?mode=translation`（僅顯示翻譯後語言）
- `http://localhost:3000/overlay.html?bg=green`（強制使用綠幕底）
- `http://localhost:3000/overlay.html?size=huge`（強制使用特大字體）
- `http://localhost:3000/overlay.html?autohide=5`（靜音 5 秒後自動隱藏）
- `http://localhost:3000/overlay.html?stroke=thick`（超粗黑邊）

## 💡 注意事項

1. **瀏覽器核心限制**：語音辨識需依賴 Google Web Speech API，因此**控制面板（講話端）請務必使用 Google Chrome 瀏覽器開啟**（系統已內建自動偵測，非 Chrome 瀏覽器開啟時將跳出提示通知）。
2. **麥克風權限**：首次開啟時，瀏覽器會跳出麥克風使用權限提示，請點選「允許」。
3. 只要保持後台 `npm start` 執行，即可隨時在實況中無限制使用。
